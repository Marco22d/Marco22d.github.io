Condiciones del servicio

Última actualización: 21 de octubre de 2026

Estas condiciones describen el uso previsto de automatizacion, una integración de uso personal para administrar páginas de Facebook autorizadas.

1. Acceso autorizado

La aplicación está destinada al operador y a las cuentas que este autorice expresamente. Para conectar una página es necesario contar con los permisos de Meta correspondientes.

2. Funcionalidades

La herramienta permite consultar conexiones autorizadas y, una vez implementadas las funciones correspondientes, preparar y enviar publicaciones a las páginas seleccionadas desde un programa Python. La disponibilidad depende de las APIs oficiales y de los permisos concedidos.

3. Responsabilidad por el contenido

El operador es responsable de revisar y aprobar el contenido antes de publicarlo, disponer de los derechos necesarios y cumplir las condiciones de Meta y la normativa aplicable. No debe utilizar la integración para suplantar identidades, enviar contenido no autorizado o vulnerar derechos de terceros.

4. Servicios de terceros

La herramienta depende de servicios externos, incluidos Meta y Microsoft Azure. Sus cambios de API, límites, incidencias o restricciones pueden afectar el funcionamiento.

5. Suspensión y revocación

El operador puede dejar de utilizar la integración y revocar permisos desde Facebook en cualquier momento. Los datos asociados pueden eliminarse siguiendo las instrucciones correspondientes.

6. Contacto

Para consultas sobre el uso de la aplicación, escribe a CONTACTO@EJEMPLO.COM.
