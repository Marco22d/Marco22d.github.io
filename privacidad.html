Política de privacidad

Última actualización: 21 de octubre de 2026

Esta política describe el tratamiento de información relacionado con la aplicación automatizacion, una herramienta para conectar páginas de Facebook autorizadas y gestionar contenido desde Python.

1. Responsable y contacto

El responsable de la aplicación es su operador individual. Para consultas sobre privacidad, escribe a marco3321@outlook.es.

2. Información que puede tratar la aplicación

Cuando la cuenta autoriza la conexión mediante Meta, la aplicación puede acceder a la información necesaria para gestionar las páginas autorizadas: identificadores y nombres de páginas, permisos y tareas concedidas, identificadores de cuenta relacionados con la autorización, códigos temporales OAuth, tokens de acceso y contenido que el propio operador decida publicar.

3. Finalidades

  • Autenticar la conexión con Meta y mantener las autorizaciones vigentes.
  • Consultar qué páginas están disponibles para la cuenta autorizada.
  • Permitir seleccionar páginas y, cuando se habilite esa función, enviar publicaciones expresamente aprobadas por el operador.
  • Diagnosticar errores técnicos y evitar operaciones no autorizadas.

4. Servicios utilizados

La autenticación y la administración de páginas utilizan servicios de Meta. La aplicación puede utilizar Microsoft Azure para recibir de forma segura la respuesta de autorización OAuth. El programa principal de Python puede conservar localmente tokens y configuraciones necesarios para mantener las conexiones, de acuerdo con la implementación efectiva.

5. Conservación y seguridad

Los datos se mantienen únicamente mientras sean necesarios para las funciones autorizadas y deben protegerse contra accesos no autorizados. La autorización puede revocarse desde la configuración de Facebook. Los tokens y demás datos asociados deberán eliminarse cuando ya no se necesiten o ante una solicitud válida de eliminación, salvo obligaciones legales aplicables.

6. Compartición de datos

No se comercializan datos personales. La información indispensable puede ser procesada por Meta y Microsoft Azure para ejecutar sus servicios. El contenido que el operador decide publicar se envía a las páginas seleccionadas mediante las herramientas de Meta.

7. Solicitudes y eliminación

Para solicitar la eliminación de los datos asociados a una conexión, consulta las instrucciones de eliminación de datos o escribe a CONTACTO@EJEMPLO.COM.

8. Actualizaciones

Esta política puede actualizarse si cambian las funcionalidades o el tratamiento de información. La fecha de actualización figura al inicio.
